1. Поле heroesCreated должно быть статическим, чтобы можно было считать сумму всех объектов класса. Если сделать нестатическим, то посчитать можно будет только объект, к которому оно привязано.
2. Поля name, health и level должны быть нестатическими, поскольку они должны принадлежать конкретному объекту и переопределяться в нём.
3. printHeroesCreated() - статический метод, поэтому его можно вызвать без создания объекта класса.
4. Из статического метода нельзя напрямую обратиться к нестатическому полю name, поскольку статический метод не привязан к объекту и не знает, чей name нужно получить. Нестатическое поле существует только внутри объекта.
5. Если пометить класс Hero модификатором final, то его атрибуты нельзя будет переопределить, то есть класс нельзя будет наследовать.
6. Переменные с типом Hero, но объекты, присвоенные им, созданы от классов-наследников, в которых вызванные методы переопределены.
7. final у переменной knight означает, что нельзя присваивать этой переменной другой объект, но поля уже присвоенного объекта менять не запрещается.
